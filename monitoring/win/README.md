# Windows Sysinternals Tools

MIGHT NEED TO RENAME THESE

Main
- procexp64.exe: Process Explorer - Replaces htop. Live process tree, parent-child relationships, verified publisher signatures.
- autoruns64.exe: Autoruns - Persistence hunting. Scans registry run keys, scheduled tasks, startup services, and AppInit DLLs.
- procmon64.exe: Process Monitor - Replaces pspy. Real-time file system edits, registry modifications, and process creation.
- tcpview64.exe: TCPView - Replaces ss -tulpn. Displays active listening ports, open TCP/UDP sockets, and attached process IDs.
- logonsessions64.exe: LogonSessions - Replaces whowatch. Lists active user sessions and remote authentication types.

Extras
- accesschk64.exe: AccessChk - Check file, registry, service permissions.
- handle64.exe: Handle - Display open handles for processes.
- procdump64.exe: ProcDump - Process memory dump utility for debugging.
- psexec64.exe: PsExec - Execute processes remotely/locally with different credentials.
- pskill64.exe: PsKill - Terminate local/remote processes.
- tcpvcon64.exe: TCPVCon - Command-line version of TCPView.
